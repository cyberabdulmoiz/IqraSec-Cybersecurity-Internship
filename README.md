🔬 Development & Testing Methodology

Each project follows a structured development process:

1. Requirement Analysis — Understand the assigned problem and expected functionality.
2. Solution Design — Identify the required commands, libraries, and program logic.
3. Implementation — Develop the tool using the appropriate programming language.
4. Testing — Execute the tool with representative inputs and observe its behavior.
5. Debugging — Identify and correct errors or unexpected results.
6. Documentation — Record usage instructions, screenshots, limitations, and improvements.
7. Version Control — Maintain project changes through GitHub commits.
